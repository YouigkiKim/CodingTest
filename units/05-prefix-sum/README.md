## 학습 목표

- 누적합 배열을 만들고, 임의 구간의 합을 O(1)에 구한다.
- 반열린 구간 `[l, r)`과 1-indexed 닫힌 구간 `[L, R]`을 혼동 없이 변환한다.
- 누적합과 해시를 결합해 "조건을 만족하는 구간의 수"를 센다.

## 선행 지식

[01단원](../01-array-string/README.md): `vector`. [04단원](../04-hash-set/README.md): `unordered_map`, 기록해 두고 찾기(05b에서 사용).

## 개념

배열 `a`에 대해 **누적합** `prefix[i]`를 "앞에서부터 i개의 합"으로 정의한다.

```
a      =     3   1   4   1   5   9
prefix = 0   3   4   8   9  14  23
index    0   1   2   3   4   5   6
```

```cpp
vector<long long> prefix(n + 1, 0);
for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + a[i];
```

- 크기는 **n + 1**, `prefix[0] = 0`.
- 0-indexed 반열린 구간 `[l, r)`의 합 = `prefix[r] - prefix[l]`
- 1-indexed 닫힌 구간 `[L, R]`의 합 = `prefix[R] - prefix[L - 1]`

"앞에서 r개의 합"에서 "앞에서 l개의 합"을 빼면 그 사이의 합만 남는다는 단순한 원리다.

### 왜 반열린 구간인가

`[l, r)`로 생각하면 길이가 `r - l`, 합이 `prefix[r] - prefix[l]`로 **+1, -1 보정이 사라진다.**
문제가 1-indexed 닫힌 구간 `[L, R]`로 주어지면 `l = L - 1, r = R`로 바꾸면 된다.

## 이런 문제에서 떠올린다

| 문제의 특징 | 떠올릴 것 |
|---|---|
| "구간의 합"을 **여러 번** 묻는다 | 누적합 전처리 후 O(1) 응답 |
| 배열은 바뀌지 않고 질문만 많다 | 누적합 (값이 중간에 바뀌면 다른 자료구조 필요 - 이 과정 범위 밖) |
| "합이 K인 구간의 수", "합이 M의 배수인 구간의 수" | 누적합 + 해시 |
| 구간 평균, 구간 내 특정 조건의 개수 | 조건을 0/1로 바꾼 배열의 누적합 |

## 작은 입력으로 따라가기

`a = [3, 1, 4, 1, 5, 9]`, 질문 "2번째부터 5번째까지의 합" (L=2, R=5)

1. `prefix[5] = 14` (앞 5개: 3+1+4+1+5)
2. `prefix[1] = 3` (앞 1개: 3)
3. `14 - 3 = 11` = 1+4+1+5 ✔

**누적합 + 해시** (05b의 핵심): 구간 `(i, j]`의 합이 K ⇔ `prefix[i] == prefix[j] - K`.
j를 늘려 가면서 "앞에서 `prefix[j] - K`가 몇 번 나왔는가"를 맵에서 찾는다. 04단원의 패턴과 같다.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 누적합 만들기 | O(N) | O(N) |
| 구간 합 질문 1개 | O(1) | - |
| Q개 질문 전체 | O(N + Q) | O(N) |
| 직접 더하기(비교) | O(N × Q) | - |

N = Q = 200,000이면 직접 더하기는 최대 4×10^10번, 누적합은 40만 번이다.

## 자주 하는 실수와 반례

| 실수 | 반례 / 증상 |
|---|---|
| `prefix[R] - prefix[L]` (닫힌 구간에서) | `a=[1,2,3]`, [1,3] → 5 (a_1이 빠짐) |
| `prefix` 크기를 n으로 | `prefix[n]` 접근 시 범위 밖 |
| `prefix`를 `int`로 | 10^9짜리 3개만 더해도 오버플로 |
| `prefix[0] = a[0]` 방식으로 만들고 `l = 0`을 특별 처리하다 실수 | 크기 n+1 방식을 쓰면 특별 처리가 없다 |
| 누적합+해시에서 `seen[0] = 1` 누락 | 맨 앞에서 시작하는 구간을 세지 못함 |
| 음수가 있는 배열에 슬라이딩 윈도우 적용 | [08단원](../08-two-pointers/README.md) 참고. 누적합+해시는 음수에도 성립 |
