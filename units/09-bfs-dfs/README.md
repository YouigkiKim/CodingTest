## 개념

### 그래프와 인접 리스트

**그래프**는 정점(점)과 간선(점을 잇는 선)의 모음이다. 도시와 도로, 사람과 친구 관계, 격자의 칸과 이웃 칸 등.

```cpp
vector<vector<int>> adj(n);        // adj[u] = u와 연결된 정점 목록
adj[u].push_back(v);
adj[v].push_back(u);               // 양방향 간선이면 양쪽에 넣는다
```

격자는 따로 저장할 필요 없이 "칸 = 정점, 상하좌우 이웃 = 간선"으로 본다.

### 탐색: 한 정점에서 갈 수 있는 모든 정점 방문하기

| | DFS (깊이 우선) | BFS (너비 우선) |
|---|---|---|
| 방문 순서 | 한 방향으로 끝까지 간 뒤 되돌아옴 | 시작점에서 가까운 순서 |
| 구현 | 재귀 또는 스택 | 큐 |
| 최단 거리 | 보장하지 않음 | **간선 비용이 모두 같으면** 보장 |
| 주 용도 | 연결 여부, 연결 요소 | 최단 거리, 연결 요소 |

두 방법 모두 **방문 표시**가 핵심이다. 표시하지 않으면 같은 정점을 끝없이 다시 방문한다.

### BFS의 기본 형태 (외울 것)

```cpp
vector<int> dist(n, -1);           // -1 = 미방문
queue<int> q;
dist[start] = 0;                   // (1) 시작점을 방문 처리하고
q.push(start);                     //     큐에 넣는다
while (!q.empty()) {
    int cur = q.front(); q.pop();
    for (int next : adj[cur]) {
        if (dist[next] != -1) continue;   // (2) 이미 방문했으면 건너뜀
        dist[next] = dist[cur] + 1;       // (3) 큐에 "넣을 때" 방문 처리
        q.push(next);
    }
}
```

**큐에 넣는 순간 방문 처리**한다. 꺼낼 때 처리하면, 그 사이에 같은 정점이 여러 번 큐에 들어가 느려지거나 메모리가 부족해진다.

### 격자 BFS에서 이웃 확인 순서

```cpp
int nr = r + dr[d], nc = c + dc[d];
if (nr < 0 || nr >= h || nc < 0 || nc >= w) continue;  // 1. 범위
if (grid[nr][nc] == '#') continue;                      // 2. 갈 수 있는 칸인가
if (dist[nr][nc] != -1) continue;                       // 3. 방문했는가
```

### 재귀 DFS와 스택 깊이

재귀 DFS는 코드가 짧지만, 경로가 길면 재귀가 깊어진다. 500×500 격자가 한 줄로 이어져 있으면 깊이가 10만을 넘고,
환경에 따라 **스택 오버플로**(런타임 오류)가 난다. 격자 문제에서는 BFS를 기본으로 쓰는 것이 안전하다.

## 이런 문제에서 떠올린다

| 문제의 특징 | 떠올릴 것 |
|---|---|
| "연결된 덩어리의 개수", "영역의 수", "섬" | 미방문 칸마다 BFS/DFS 시작 → 시작 횟수가 답 |
| "A에서 B로 갈 수 있는가" | BFS/DFS 한 번 |
| "최소 이동 횟수", "최단 거리" + 한 번 이동 비용이 모두 같음 | BFS |
| "몇 분 뒤 모두 퍼지는가", 동시에 번짐 | 시작점 여러 개를 큐에 넣고 BFS |
| 간선마다 비용이 다르다 | BFS로는 안 된다(다익스트라 - 이 과정 범위 밖) |

## 작은 입력으로 따라가기

간선: 0-1, 0-2, 1-3, 2-3, 3-4. 0에서 BFS.

| 꺼낸 정점 | 새로 방문(거리) | 큐 (앞→뒤) |
|---|---|---|
| (시작) | 0(0) | 0 |
| 0 | 1(1), 2(1) | 1 2 |
| 1 | 3(2) | 2 3 |
| 2 | (3은 이미 방문) | 3 |
| 3 | 4(3) | 4 |
| 4 | - | (빔) |

2를 꺼냈을 때 3은 이미 `dist`가 정해져 있어 다시 넣지 않는다. 이것이 "넣을 때 방문 처리"의 효과다.
거리 0 → 1 → 2 → 3 순으로 방문하므로 처음 기록된 거리가 최단이다.

## 복잡도

- 시간 O(V + E): 각 정점은 한 번 큐에 들어가고(V), 각 간선은 양 끝에서 한 번씩 확인된다(E).
- 격자: 정점 H×W개, 정점당 이웃 4개 → O(H×W).
- 공간 O(V + E)(인접 리스트) 또는 O(H×W)(격자, 방문 배열, 큐).

## 자주 하는 실수와 반례

| 실수 | 반례 / 증상 |
|---|---|
| 큐에서 꺼낼 때 방문 처리 | 빈 격자 500×500에서 같은 칸이 여러 번 들어가 매우 느려짐 |
| 방문 처리 누락 | 무한 반복 |
| 범위 검사 전에 `grid[nr][nc]` 접근 | 가장자리 칸에서 범위 밖 접근 |
| 최단 거리에 DFS 사용 | 먼 길로 먼저 도착한 값을 답으로 냄 |
| 재귀 DFS로 큰 격자 탐색 | 뱀 모양 격자에서 스택 오버플로(SIGSEGV) |
| `'.'`만 이동 가능으로 처리 | 도착 칸 `E`에 들어가지 못함 → "벽이 아니면 이동" |
| 양방향 간선을 한쪽만 추가 | 반대 방향으로 이동 불가 |
| 정점 번호가 1부터인데 크기 n 배열 | `adj[n]` 범위 밖 → 크기 n+1 |
| 도달 불가를 0으로 출력 | 문제는 보통 -1을 요구 |
