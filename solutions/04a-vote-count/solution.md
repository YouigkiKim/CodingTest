# 04a 투표 집계 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/04a-vote-count/problem.md)

## 접근

01a(점수 분포)와 같은 "빈도 세기"지만 키가 문자열이라 배열 인덱스로 쓸 수 없다.
이럴 때 `unordered_map<string, int>`가 빈도 배열을 대신한다.

1. `votes[name]++`로 득표수를 센다.
2. 맵 전체를 돌며 `(득표수가 더 많다) 또는 (같고 이름이 사전순으로 앞선다)`일 때 갱신한다.

`map<string,int>`를 쓰면 키가 사전순으로 순회되므로 `count > best_count`만 검사해도 된다.
대신 삽입·조회가 O(log N)이 된다. 이 문제에서는 둘 다 통과한다.

## 복잡도

- 시간: 평균 O(N) (문자열 길이 ≤ 10을 상수로 볼 때). `map`이면 O(N log N).
- 공간: O(서로 다른 이름 수).

## 자주 하는 실수

- `unordered_map`의 순회 순서가 사전순 또는 입력순이라고 가정한다(보장되지 않는다).
- 이름을 전부 `vector`에 넣고 이름마다 `count()`를 호출하는 O(N²) 풀이 → 시간초과.
- 동률 처리 누락.
