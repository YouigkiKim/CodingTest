# 03b 배달 순서 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/03b-delivery-order/problem.md)

## 접근

출발지(1번)는 고정이고 나머지 N-1곳의 **방문 순서**만 정하면 된다.
N ≤ 8이므로 순서의 수는 최대 7! = 5,040가지. 전부 만들어 보고 최솟값을 고른다.

1. `order = {1, 2, ..., n-1}` (0-indexed 기준, 출발지는 0)
2. `do { 비용 계산 } while (next_permutation(...))`

`next_permutation`은 **현재 순열의 사전순 다음 순열**을 만들고, 더 없으면 `false`를 반환한다.
그래서 반드시 **오름차순으로 정렬된 상태에서 시작**해야 모든 순열을 본다.

## 왜 "가장 가까운 곳부터"는 안 되는가

예제 2에서 1번에서 가장 가까운 곳은 2번(거리 1)이지만, 2번에서 3번으로 가는 길이 100이다.
먼저 3번(거리 10)으로 간 뒤 2번(거리 1)으로 가면 11로 훨씬 짧다.
눈앞의 최선이 전체 최선을 보장하지 않을 때, 입력이 작으면 완전탐색이 가장 안전하다.

## 복잡도

- 시간: O((N-1)! × N) = 5,040 × 8 ≈ 4만.
- 공간: O(N²).

## 자주 하는 실수

- `while (next_permutation(...)) { ... }` 형태로 써서 **첫 순열을 건너뜀** → `do-while`을 쓴다.
- 출발지까지 순열에 넣어 1번이 아닌 곳에서 출발하는 경우를 센다.
- `d[i][j] ≠ d[j][i]`일 수 있는데 대칭이라고 가정한다.
