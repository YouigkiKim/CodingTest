# 06a 괄호 검사 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/06a-brackets/problem.md)

## 접근

"가장 최근에 열린 괄호가 가장 먼저 닫혀야 한다" → 나중에 넣은 것을 먼저 꺼내는 **스택**.

- 여는 괄호: push.
- 닫는 괄호: 스택이 비었으면 실패. 아니면 top을 꺼내 종류가 맞는지 확인.
- 문자열을 다 본 뒤 스택이 비어 있어야 성공.

괄호가 한 종류라면 개수만 세어도 되지만, 종류가 여러 개면 `([)]`처럼 개수는 맞아도
순서가 틀린 경우가 있어 스택이 필요하다.

## 복잡도

- 시간: O(전체 문자열 길이). 공간: O(가장 긴 문자열 길이).

## 자주 하는 실수

- 빈 스택에 `top()`/`pop()` 호출 → 정의되지 않은 동작. 입력 `)` 하나로 재현된다.
- 마지막에 `st.empty()` 확인 누락 → `((`를 YES로 답한다.
- `char open = st.pop();` → `pop()`은 값을 반환하지 않는다. `top()`으로 읽고 `pop()`으로 제거.
