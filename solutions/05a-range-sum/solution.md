# 05a 구간 합 질의 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/05a-range-sum/problem.md)

## 접근

질문마다 구간을 직접 더하면 최악 O(N×Q) = 4×10^10. 불가능하다.

**누적합** `prefix[i] = a_1 + ... + a_i` (그리고 `prefix[0] = 0`)를 한 번 만들어 두면
`[l, r]`의 합은 `prefix[r] - prefix[l-1]` 한 번의 뺄셈으로 구한다.

`prefix` 크기를 `n + 1`로 잡고 `prefix[0] = 0`을 두는 것이 요령이다.
이렇게 하면 `l = 1`일 때도 특별 처리가 필요 없다.

## 자료형

합의 최댓값은 200,000 × 10^9 = 2×10^14 → `long long` 필수.

## 복잡도

- 시간: O(N + Q) - 전처리 O(N), 질문당 O(1).
- 공간: O(N).

## 자주 하는 실수

- `prefix[r] - prefix[l]`로 써서 `a_l`을 빠뜨린다(1-indexed 닫힌 구간이면 `l-1`).
- `prefix`를 `vector<int>`로 선언해 오버플로.
- 입출력이 40만 줄이므로 `endl`을 쓰면 매우 느려진다 → `'\n'`.
