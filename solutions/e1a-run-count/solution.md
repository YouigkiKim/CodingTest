# 모의 1-1 연속 문자 세기 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/e1a-run-count/problem.md)

**사용한 방법: 문자열 구현(연속 구간 묶기)** - 관련 단원 [01](../../units/01-array-string/README.md)

## 접근

구간의 시작 `i`를 잡고, 같은 문자가 이어지는 동안 `j`를 늘린다. `[i, j)`가 한 덩어리이고 길이는 `j - i`.
덩어리를 출력한 뒤 `i = j`로 건너뛴다.

"이전 문자와 다르면 지금까지 센 것을 출력" 방식으로도 풀 수 있지만, 그 방식은
**마지막 덩어리를 반복문이 끝난 뒤 따로 출력**해야 해서 실수가 잦다. 위의 `[i, j)` 방식은 그 문제가 없다.

## 복잡도

- 시간: O(|S|) - `j`가 전체 문자열을 한 번만 지나간다. 공간: O(|S|).

## 자주 하는 실수

- 마지막 덩어리 출력 누락(입력 `aab` → `a2`만 출력).
- 개수가 10 이상일 때 `char('0' + count)`로 변환 → 깨진 문자. `to_string`을 쓴다.
- 문자별 전체 빈도를 세는 것으로 오해(`aabaa` → `a4b1`은 오답, `a2b1a2`가 정답).
