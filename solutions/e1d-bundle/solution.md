# 모의 1-4 묶음 포장 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/e1d-bundle/problem.md)

**사용한 방법: 누적합 + 나머지별 빈도(해시)** - 관련 단원 [05](../../units/05-prefix-sum/README.md), [04](../../units/04-hash-set/README.md)

## 접근

구간 `(i, j]`의 합은 `prefix[j] - prefix[i]`. 이것이 M의 배수라는 것은

```
prefix[j] % M == prefix[i] % M
```

과 같다. 따라서 **누적합을 M으로 나눈 나머지가 같은 위치 쌍의 수**를 세면 된다.
왼쪽부터 보면서 "지금 나머지와 같은 나머지가 앞에서 몇 번 나왔는가"를 더한다.
(05b '합이 K인 구간'에서 찾는 값이 `prefix - K`에서 `같은 나머지`로 바뀐 것이다.)

`seen[0] = 1`: 맨 앞에서 시작하는 구간을 위해 "누적합 0"을 미리 넣는다.

### 예제 1 (1 2 3 4 5, M = 3)

누적합: 0 1 3 6 10 15 → 나머지: 0 1 0 0 1 0
나머지 0이 4번 → 쌍 4×3/2 = 6, 나머지 1이 2번 → 쌍 1. 합계 7.

## 구현 메모

- M이 최대 10^9이라 크기 M짜리 배열은 만들 수 없다 → `unordered_map`.
- 누적합 전체를 저장할 필요 없이 나머지만 들고 다니면 된다. `(prefix_mod + x)`는 최대 약 2×10^9 → `long long`.
- 답은 최대 N(N+1)/2 ≈ 2×10^10 → `long long`.

## 복잡도

- 시간: 평균 O(N). 공간: O(N).

## 자주 하는 실수

- 모든 구간을 직접 검사하는 O(N²).
- `seen[0] = 1` 누락.
- `vector<int> cnt(M)`으로 선언해 메모리 초과/런타임 오류.
- 답을 `int`로 선언.
