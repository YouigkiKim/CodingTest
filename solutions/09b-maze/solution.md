# 09b 미로 탈출 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/09b-maze/problem.md)

## 접근

모든 이동의 비용이 1로 같다 → **BFS**가 최단 거리를 보장한다.

BFS는 출발점에서 가까운 칸부터 차례로(거리 0, 1, 2, …) 방문한다.
따라서 어떤 칸을 **처음** 방문했을 때의 거리가 곧 최단 거리다.

- `dist` 배열을 -1로 초기화해 "방문 여부"와 "거리"를 한 번에 관리한다.
- 큐에 넣는 순간 `dist[next] = dist[cur] + 1`을 기록한다.
- 끝까지 돌고 `dist[E]`를 출력한다. 닿지 못했다면 -1이 그대로 남아 있다.

## DFS로는 왜 안 되는가

DFS는 한 방향으로 끝까지 들어가므로 처음 도착한 경로가 최단이라는 보장이 없다.
모든 경로를 다 비교하도록 고치면 지수 시간이 걸린다.

## 복잡도

- 시간: O(H×W) = 2.5×10^5. 공간: O(H×W).

## 자주 하는 실수

- 'S'나 'E' 칸을 벽으로 취급(`grid == '.'`일 때만 이동하도록 작성). 벽이 **아닌** 칸으로 이동한다고 써야 한다.
- 꺼낼 때 방문 처리해 같은 칸이 여러 번 큐에 들어간다.
- 도달 불가 시 -1 대신 0이나 큰 수를 출력.
- 거리 대신 "BFS 반복 횟수"를 세어 엉뚱한 값을 출력.
