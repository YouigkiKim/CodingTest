# 01b 로봇 이동 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/01b-robot-walk/problem.md)

## 접근

문제에 적힌 규칙을 그대로 옮기는 **시뮬레이션**이다. 핵심은 방향을 숫자로 표현하는 것.

- 방향을 `0=동, 1=남, 2=서, 3=북`처럼 **시계 방향 순서**로 번호를 매긴다.
- 오른쪽 회전은 `(dir + 1) % 4`, 왼쪽 회전은 `(dir + 3) % 4`.
- 방향별 이동량을 배열 `dr[]`, `dc[]`에 넣어 두면 `if`를 네 번 쓰지 않아도 된다.
- 전진할 때는 **먼저 다음 칸을 계산하고**, 격자 안일 때만 실제 위치를 바꾼다.

행 번호는 아래(남쪽)로 갈수록 커진다는 점에 주의한다. 그래서 남쪽은 `dr = +1`이다.

## 복잡도

- 시간: O(|S|) - 명령 하나당 상수 시간.
- 공간: O(|S|) - 명령 문자열 저장. 격자 자체는 만들 필요가 없다.

## 자주 하는 실수

- 왼쪽 회전을 `(dir - 1) % 4`로 쓰면 C++에서 `-1 % 4 == -1`이라 배열 범위를 벗어난다.
- 북쪽을 `dr = +1`로 두는 좌표 방향 착각.
- 범위 검사 전에 위치를 먼저 바꾸고 되돌리지 않는 실수.
- 1000×1000 격자를 굳이 2차원 배열로 만드는 것 - 필요 없다.
