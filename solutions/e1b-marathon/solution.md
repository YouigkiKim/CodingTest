# 모의 1-2 마라톤 기록 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/e1b-marathon/problem.md)

**사용한 방법: 문자열 파싱 + 정렬** - 관련 단원 [01](../../units/01-array-string/README.md), [02](../../units/02-sorting/README.md)

## 접근

1. `HH:MM:SS`를 초로 바꾼다. 자리 수가 고정이므로 `substr(0,2)`, `substr(3,2)`, `substr(6,2)`에 `stoi`.
2. `(초, 이름)` 쌍으로 저장해 정렬한다. `pair`의 기본 비교가 곧 "기록 오름차순, 같으면 이름 사전순"이라
   비교 함수를 따로 쓸 필요가 없다. **정렬 기준 순서대로 pair에 넣는 것**이 요령이다.
3. 1등의 기록을 빼서 출력한다.

## 복잡도

- 시간: O(N log N). 공간: O(N).
- 최대 99:59:59 = 359,999초 → `int`로 충분.

## 자주 하는 실수

- `(이름, 초)` 순서로 pair를 만들어 이름 기준으로 정렬된다.
- 차이를 `HH:MM:SS` 형식으로 출력(문제는 초 단위 정수를 요구).
- 시·분·초 변환에서 3600과 60을 뒤바꾼다.
