# 04b 합이 T인 쌍 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/04b-pair-sum-count/problem.md)

## 접근

모든 쌍을 보는 O(N²)은 N=200,000에서 2×10^10번이라 불가능하다.

배열을 왼쪽부터 보면서, 현재 값 `x`의 짝이 되려면 앞에서 `T - x`가 나왔어야 한다.
"앞에서 값 v가 몇 번 나왔는가"를 해시맵에 기록해 두면 O(1)에 답할 수 있다.

```
for x in a:
    pairs += seen[T - x]   // x를 오른쪽 원소로 하는 쌍의 수
    seen[x] += 1           // 그 다음에 자신을 등록
```

**먼저 세고, 나중에 등록**하기 때문에 자기 자신과 짝지어지는 일이 없고 각 쌍이 정확히 한 번 세어진다.

## 자료형

- 답: 모든 값이 같으면 N(N-1)/2 = 19,999,900,000 → `long long`.
- `T - x`: 최대 2×10^9 + 10^9 → `int` 범위 초과 → `long long`으로 계산.

## 복잡도

- 시간: 평균 O(N).
- 공간: O(N).

## 자주 하는 실수

- 답을 `int`로 선언(테스트에 모든 값이 같은 경우가 있다).
- 먼저 전부 등록한 뒤 세어서 `x + x = T`인 경우 자기 자신을 짝으로 센다.
- `seen[T - x]`처럼 `[]`로 조회 → 답은 맞지만 없는 키가 맵에 계속 추가되어 메모리와 시간이 늘어난다.
  조회만 할 때는 `find` 또는 `count`를 쓴다.
