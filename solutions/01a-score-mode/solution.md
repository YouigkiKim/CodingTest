# 01a 점수 분포 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/01a-score-mode/problem.md)

## 접근

값의 범위가 0~100으로 작다. 값 자체를 인덱스로 쓰는 **빈도 배열** `cnt[score]`를 만들면
한 번 훑는 것만으로 각 점수가 몇 번 나왔는지 알 수 있다.

1. `cnt[x]++`로 빈도를 센다.
2. 점수 0부터 100까지 오름차순으로 보면서 `cnt[s] > cnt[best]`일 때만 갱신한다.
   `>`(초과)를 쓰기 때문에 동률이면 먼저 본 작은 점수가 유지된다.

## 복잡도

- 시간: O(N + 101) - 입력을 한 번 읽고, 빈도 배열을 한 번 훑는다.
- 공간: O(101) - 입력 배열을 저장할 필요도 없다.

## 자주 하는 실수

- `vector<int> cnt(100)`으로 만들면 점수 100에서 범위를 벗어난다. 값의 범위가 0~100이면 크기는 **101**.
- 갱신 조건을 `>=`로 쓰면 동률일 때 큰 점수가 선택된다.
- 모든 점수 쌍을 비교하는 O(N²) 풀이는 N=200,000에서 시간초과가 난다.
