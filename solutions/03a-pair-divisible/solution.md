# 03a 짝 고르기 - 해설

[정답 코드](solution.cpp) · [문제](../../problems/03a-pair-divisible/problem.md)

## 접근

N ≤ 2,000이므로 모든 쌍의 수는 N(N-1)/2 ≈ 200만 개. 전부 검사해도 충분히 빠르다.
`i < j`인 쌍만 보도록 안쪽 반복문을 `j = i + 1`부터 시작한다.

## 자료형

`a_i ≤ 10^9`이므로 두 수의 합은 최대 2×10^9이다. `int` 최댓값(약 2.147×10^9)을 아슬아슬하게 넘지 않지만,
세 수의 합이었거나 제한이 조금만 컸어도 오버플로다. 값이 10^9 근처인 수를 더하거나 곱할 때는
계산해 보고, 확신이 없으면 `long long`을 쓴다. 답 자체는 최대 1,999,000이라 `int`로 충분하다.

## 복잡도

- 시간: O(N²) ≈ 2×10^6 번의 검사.
- 공간: O(N).

## 자주 하는 실수

- `j = 0`부터 돌려서 같은 쌍을 두 번 세거나 자기 자신과 짝짓는다.
- N이 20만이었다면 이 풀이는 불가능하다. 그때는 나머지별 개수를 세는 방법(04단원)이 필요하다.
  **입력 제한을 보고 완전탐색이 가능한지 먼저 계산하는 것**이 이 문제의 요점이다.
