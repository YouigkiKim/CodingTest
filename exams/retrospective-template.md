# 모의시험 회고 양식

[모의시험 목록](README.md) · [전체 목차](../README.md)

이 파일을 복사해서 작성한다. 예: `cp exams/retrospective-template.md exams/retro-exam1.md`
(`exams/retro-*.md`는 개인 기록이므로 자유롭게 만들고 고쳐도 된다.)

회고의 목적은 점수 기록이 아니라 **다음 시험에서 바꿀 행동**을 찾는 것이다. 시험 직후, 해설을 보기 전에 3~5번 항목을 먼저 적는다.

## 오류 원인 분류표 (참고)

| 분류 | 예 |
|---|---|
| 문제 이해 | 조건 누락, 출력 형식, 동률 규칙, 구간 정의(닫힌/반열린) |
| 방법 선택 | 복잡도 계산 안 함, 그리디 반례 미확인, 단조성 미확인 |
| 자료형 | int 오버플로, 정수 나눗셈 |
| 경계조건 | N=1, 빈 결과, 답 없음, 첫/마지막 원소, 음수 |
| 구현 | 인덱스 범위, 초기화, 빈 컨테이너 접근, 방문 처리 시점 |
| 시간 관리 | 한 문제에 과도한 시간, 쉬운 문제를 뒤로 미룸 |

자세한 목록은 [자주 하는 실수](../docs/pitfalls.md) 참고.
