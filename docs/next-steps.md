# 추후 학습 목록

[전체 목차](../README.md)

이 과정에서 **의도적으로 제외한** 주제들이다. 00~12단원과 모의시험을 마치고, 기초 문제를 안정적으로 풀 수 있게 된 뒤에 진행한다.
아래 순서는 기초 과정과의 연결이 가까운 것부터 나열한 것이다.

## 기초 범위의 확장

| 주제 | 한 줄 설명 | 이어지는 단원 |
|---|---|---|
| 비트마스크로 부분집합 순회 | 정수의 비트로 "고른다/안 고른다"를 표현해 2^N가지를 순회 | [03](../units/03-brute-force/README.md) |
| 백트래킹 | 재귀로 경우를 만들다가 가망 없는 가지를 일찍 포기 | [03](../units/03-brute-force/README.md) |
| 2차원 누적합, 차분 배열 | 직사각형 영역 합, 구간에 값을 일괄 더하기 | [05](../units/05-prefix-sum/README.md) |
| 단조 스택, deque | "다음으로 큰 원소", 구간 최솟값 유지 | [06](../units/06-stack-queue-heap/README.md) |
| 실수 이분탐색, 삼분탐색 | 연속 값에서의 탐색 | [07](../units/07-binary-search/README.md) |
| 구현 심화 | 회전, 날짜·시간, 복잡한 시뮬레이션 | [01](../units/01-array-string/README.md) |

## 그래프

| 주제 | 한 줄 설명 |
|---|---|
| 다익스트라 | 간선 비용이 서로 다른(음수 없는) 그래프의 최단 거리. 우선순위 큐 사용 |
| 0-1 BFS, 상태가 붙은 BFS | (위치, 추가 상태)를 정점으로 보는 탐색 |
| 위상 정렬 | 선후 관계가 있는 작업의 순서 정하기 |
| 유니온 파인드 | 집합 합치기와 같은 집합 여부 판정 |
| 최소 신장 트리 | 모든 정점을 최소 비용으로 연결 |
| 플로이드-워셜, 벨만-포드 | 모든 쌍 최단 거리, 음수 간선 |
| 트리 | 트리 순회, 지름, 최소 공통 조상(LCA) |

## DP 심화

| 주제 | 한 줄 설명 |
|---|---|
| 배낭 문제 | 용량 제한 안에서 가치 최대화 |
| 최장 증가 부분 수열(LIS), 최장 공통 부분 수열(LCS) | 수열·문자열 DP의 대표 유형 |
| 구간 DP, 비트마스크 DP, 트리 DP | 상태 설계가 복잡한 DP |

## 자료구조·기타

| 주제 | 한 줄 설명 |
|---|---|
| 세그먼트 트리, 펜윅 트리 | 값이 바뀌는 배열에서의 구간 질의 |
| 문자열 알고리즘 | KMP, 해싱, 트라이 |
| 정수론 기초 | 최대공약수, 소수 판별·체, 모듈러 거듭제곱 |
| 조합론 | 이항 계수, 모듈러 역원 |

## 학습 방식 제안

- 새 주제 하나를 배우면, 이 과정의 단원 구성(개념 → 작은 예 → 예제 코드 → 기본 문제 → 응용 문제)을 그대로 따라 정리해 둔다.
- 기초 단원의 문제를 **시간을 재며 다시 푸는 복습**을 병행한다. 심화보다 기초 문제를 빠르고 정확하게 푸는 것이 먼저다.
