# 06b 막대 합치기

단원: [06 스택·큐·힙](../../units/06-stack-queue-heap/README.md) · 난이도: 응용

## 문제

길이가 각각 주어진 막대 N개가 있다. 막대 두 개를 골라 이어 붙이면 길이가 두 막대의 합인 막대 하나가 되고,
이때 **두 막대 길이의 합만큼 비용**이 든다. 이어 붙인 막대도 다시 다른 막대와 이어 붙일 수 있다.

모든 막대를 하나로 만들 때까지 드는 비용 합의 최솟값을 구하라.

## 입력

- 첫째 줄: N
- 둘째 줄: 막대 길이 N개

## 출력

최소 총비용을 출력한다. 막대가 처음부터 하나라면 0이다.

## 제한

- 1 ≤ N ≤ 200,000
- 1 ≤ 막대 길이 ≤ 10^9

## 예제

### 예제 1

입력
```
3
1 2 3
```
출력
```
9
```
1과 2를 합친다(비용 3, 막대: 3 3). 3과 3을 합친다(비용 6). 합계 9.
다른 순서: 2와 3을 먼저 합치면(5) 그다음 1과 5(6)로 합계 11.

### 예제 2

입력
```
4
10 1 1 1
```
출력
```
18
```
1+1(비용 2) → 2+1(비용 3) → 3+10(비용 13). 합계 18.
