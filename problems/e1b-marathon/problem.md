# 모의 1-2 마라톤 기록

[모의시험 1](../../exams/exam1/README.md) · 2번

## 문제

마라톤 대회 참가자 N명의 이름과 완주 기록이 주어진다. 기록은 `HH:MM:SS` 형식(시:분:초, 각각 두 자리)이다.

기록이 **짧은** 사람부터 순서대로 출력하되, 기록이 같으면 이름이 사전순으로 앞서는 사람을 먼저 출력한다.
각 참가자에 대해 이름과, **1등과의 기록 차이(초 단위 정수)**를 출력하라. 1등(및 1등과 기록이 같은 사람)의 차이는 0이다.

## 입력

- 첫째 줄: N
- 다음 N개 줄: 이름과 기록이 공백으로 구분되어 주어진다.

## 출력

N개 줄에 걸쳐, 순위 순서대로 이름과 1등과의 차이(초)를 공백으로 구분해 출력한다.

## 제한

- 1 ≤ N ≤ 100,000
- 이름: 영어 소문자 1~10자, 서로 다르다.
- 00 ≤ HH ≤ 99, 00 ≤ MM ≤ 59, 00 ≤ SS ≤ 59

## 예제

### 예제 1

입력
```
3
kim 01:00:00
lee 00:59:59
park 01:00:01
```
출력
```
lee 0
kim 1
park 2
```

### 예제 2

입력
```
3
b 00:10:00
a 00:10:00
c 00:09:00
```
출력
```
c 0
a 60
b 60
```
a와 b는 기록이 같으므로 사전순으로 a가 먼저다.
