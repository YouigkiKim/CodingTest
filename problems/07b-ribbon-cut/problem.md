# 07b 리본 자르기

단원: [07 이분탐색](../../units/07-binary-search/README.md) · 난이도: 응용

## 문제

길이가 각각 주어진 리본 N개가 있다. 이 리본들을 잘라 **길이가 모두 같은** 조각을 K개 이상 만들려고 한다.
조각의 길이는 양의 정수여야 하고, 리본을 이어 붙일 수는 없다. 자르고 남은 부분은 버린다.

만들 수 있는 조각 길이의 최댓값을 구하라. 길이 1짜리 조각으로도 K개를 만들 수 없다면 0을 출력한다.

## 입력

- 첫째 줄: N K
- 둘째 줄: 리본 길이 N개

## 출력

조각 길이의 최댓값(불가능하면 0)을 출력한다.

## 제한

- 1 ≤ N ≤ 100,000
- 1 ≤ K ≤ 10^9
- 1 ≤ 리본 길이 ≤ 10^9

## 예제

### 예제 1

입력
```
3 4
10 7 5
```
출력
```
5
```
길이 5로 자르면 2 + 1 + 1 = 4조각. 길이 6으로 자르면 1 + 1 + 0 = 2조각이라 부족하다.

### 예제 2

입력
```
2 5
1 2
```
출력
```
0
```
길이 1로 잘라도 3조각뿐이다.
