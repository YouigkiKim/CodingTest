# 07b 리본 자르기 - 힌트

[문제로 돌아가기](problem.md)

힌트는 한 단계씩만 펼쳐 보세요. 1단계를 보고 최소 10분은 다시 시도한 뒤 2단계를 보는 것을 권장합니다.

<details>
<summary>힌트 1단계</summary>

"최대 길이는?"을 바로 구하기는 어렵다. 질문을 바꿔 보자:
"조각 길이를 L로 **정했을 때** K개 이상 만들 수 있는가?" 이것은 쉽게 계산된다(각 리본에서 `길이 / L`개).

그리고 L이 가능하면 L보다 작은 길이도 모두 가능하다. 가능/불가능이 한 번만 바뀐다면, 그 경계는 어떻게 찾을까?

</details>

<details>
<summary>힌트 2단계</summary>

L의 범위 `1 ~ max(리본 길이)`에서 이분탐색한다.

```
lo = 0 (가능으로 취급), hi = max
while lo < hi:
    mid = lo + (hi - lo + 1) / 2      // 올림
    if 조각수(mid) >= K: lo = mid
    else:               hi = mid - 1
답 = lo
```

조각 수의 합은 `long long`으로 계산한다(최대 10^14).

</details>
