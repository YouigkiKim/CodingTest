# 03a 짝 고르기

단원: [03 완전탐색](../../units/03-brute-force/README.md) · 난이도: 기본

## 문제

카드 N장에 양의 정수가 하나씩 적혀 있다. 서로 다른 두 장을 골랐을 때
두 수의 합이 K의 배수가 되는 경우의 수를 구하라.
같은 수가 적힌 카드라도 서로 다른 카드이면 다른 경우로 센다. (i번, j번)과 (j번, i번)은 같은 경우다.

## 입력

- 첫째 줄: N K
- 둘째 줄: 카드에 적힌 수 N개

## 출력

조건을 만족하는 쌍의 개수를 출력한다.

## 제한

- 1 ≤ N ≤ 2,000
- 1 ≤ K ≤ 10^9
- 1 ≤ 카드의 수 ≤ 10^9

## 예제

### 예제 1

입력
```
4 3
1 2 3 6
```
출력
```
2
```
(1, 2) → 합 3, (3, 6) → 합 9. 두 쌍이 3의 배수다.

### 예제 2

입력
```
4 10
5 5 5 5
```
출력
```
6
```
어느 두 장을 골라도 합이 10이다. 4장 중 2장을 고르는 경우는 6가지.
