# 04b 합이 T인 쌍

단원: [04 해시·집합](../../units/04-hash-set/README.md) · 난이도: 응용

## 문제

정수 N개로 이루어진 수열 a_1, …, a_N과 정수 T가 주어진다.
`i < j`이면서 `a_i + a_j = T`인 쌍 (i, j)의 개수를 구하라.

## 입력

- 첫째 줄: N T
- 둘째 줄: a_1 … a_N

## 출력

조건을 만족하는 쌍의 개수를 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- -10^9 ≤ a_i ≤ 10^9
- -2×10^9 ≤ T ≤ 2×10^9

## 예제

### 예제 1

입력
```
5 6
1 5 3 3 7
```
출력
```
2
```
(1, 5)와 (3, 3) 두 쌍.

### 예제 2

입력
```
4 4
2 2 2 2
```
출력
```
6
```
값은 같아도 위치가 다르면 다른 쌍이다. 4개 중 2개를 고르는 6가지 모두 합이 4.
