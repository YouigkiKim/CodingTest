# 모의 2-1 우산 대여

[모의시험 2](../../exams/exam2/README.md) · 1번

## 문제

비 오는 날, N명의 사람이 우산을 빌리러 왔다. i번째 사람은 길이가 r_i **이상**인 우산만 쓸 수 있다.
대여소에는 우산 M개가 있고 j번째 우산의 길이는 s_j이다.
한 사람은 우산을 최대 하나 빌릴 수 있고, 우산 하나는 한 사람에게만 빌려줄 수 있다.

우산을 빌려 갈 수 있는 사람 수의 최댓값을 구하라.

## 입력

- 첫째 줄: N M
- 둘째 줄: r_1 … r_N
- 셋째 줄: s_1 … s_M

## 출력

우산을 빌릴 수 있는 최대 인원을 출력한다.

## 제한

- 1 ≤ N, M ≤ 200,000
- 1 ≤ r_i, s_j ≤ 10^9

## 예제

### 예제 1

입력
```
3 3
5 7 9
6 8 4
```
출력
```
2
```
5가 필요한 사람에게 6, 7이 필요한 사람에게 8을 준다. 9 이상인 우산은 없다.

### 예제 2

입력
```
2 4
10 10
1 2 3 10
```
출력
```
1
```
