# 01a 점수 분포

단원: [01 배열·문자열·구현](../../units/01-array-string/README.md) · 난이도: 기본

## 문제

N명의 시험 점수가 주어진다. 가장 많은 학생이 받은 점수(최빈값)와 그 점수를 받은 학생 수를 구하라.
가장 많이 나온 점수가 여러 개라면 그중 **가장 작은 점수**를 답한다.

## 입력

- 첫째 줄: 학생 수 N
- 둘째 줄: 점수 N개가 공백으로 구분되어 주어진다.

## 출력

최빈 점수와 그 점수를 받은 학생 수를 공백으로 구분해 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- 0 ≤ 점수 ≤ 100 (정수)

## 예제

### 예제 1

입력
```
5
70 80 70 90 80
```
출력
```
70 2
```
70점과 80점이 각각 2번으로 가장 많다. 둘 중 작은 70을 답한다.

### 예제 2

입력
```
3
100 0 50
```
출력
```
0 1
```
모든 점수가 한 번씩 나왔으므로 가장 작은 0을 답한다.
