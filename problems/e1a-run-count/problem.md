# 모의 1-1 연속 문자 세기

[모의시험 1](../../exams/exam1/README.md) · 1번

## 문제

영어 소문자로 이루어진 문자열 S가 주어진다. S를 왼쪽부터 보면서, 같은 문자가 연속으로 이어진 덩어리마다
"그 문자"와 "연속한 횟수"를 이어 붙여 하나의 문자열로 출력하라.

예를 들어 `aaabbc`는 a가 3번, b가 2번, c가 1번 연속하므로 `a3b2c1`이 된다.
횟수가 1이어도 생략하지 않는다.

## 입력

- 첫째 줄: 문자열 S

## 출력

변환한 문자열을 한 줄에 출력한다.

## 제한

- 1 ≤ |S| ≤ 100,000
- S는 영어 소문자로만 이루어진다.

## 예제

### 예제 1

입력
```
aaabbc
```
출력
```
a3b2c1
```

### 예제 2

입력
```
aabaa
```
출력
```
a2b1a2
```
같은 문자라도 떨어져 있으면 따로 센다.

### 예제 3

입력
```
zzzzzzzzzzzz
```
출력
```
z12
```
