# 10a 상자 싣기

단원: [10 그리디 기초](../../units/10-greedy/README.md) · 난이도: 기본

## 문제

무게가 각각 주어진 상자 N개와, 최대 C만큼의 무게를 실을 수 있는 트럭 한 대가 있다.
실은 상자들의 무게 합이 C를 넘지 않도록 하면서 **최대 몇 개**의 상자를 실을 수 있는지 구하라.

## 입력

- 첫째 줄: N C
- 둘째 줄: 상자 무게 N개

## 출력

실을 수 있는 상자의 최대 개수를 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- 1 ≤ 상자 무게 ≤ 10^9
- 1 ≤ C ≤ 10^15

## 예제

### 예제 1

입력
```
5 10
4 8 1 3 5
```
출력
```
3
```
무게 1, 3, 4인 상자(합 8)를 싣는다. 4개를 실으려면 최소 1+3+4+5 = 13이 필요하다.

### 예제 2

입력
```
1 5
6
```
출력
```
0
```
