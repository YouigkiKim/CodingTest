# 모의 2-3 복사기

[모의시험 2](../../exams/exam2/README.md) · 3번

## 문제

복사기 N대가 있다. i번째 복사기는 한 장을 복사하는 데 정확히 t_i초가 걸리고, 쉬지 않고 연속으로 복사할 수 있다.
모든 복사기는 시각 0에 동시에 작업을 시작하며, 각 복사기는 서로 독립적으로 동작한다.

합쳐서 K장 이상의 사본을 얻기 위해 필요한 **최소 시간(초)**을 구하라.

## 입력

- 첫째 줄: N K
- 둘째 줄: t_1 … t_N

## 출력

필요한 최소 시간을 초 단위 정수로 출력한다.

## 제한

- 1 ≤ N ≤ 100,000
- 1 ≤ K ≤ 10^9
- 1 ≤ t_i ≤ 10^9

## 예제

### 예제 1

입력
```
2 5
2 3
```
출력
```
6
```
6초 동안 첫 번째 복사기는 3장, 두 번째는 2장을 만든다. 5초에는 2 + 1 = 3장뿐이다.

### 예제 2

입력
```
2 4
3 5
```
출력
```
9
```
9초: 3 + 1 = 4장. 8초: 2 + 1 = 3장.

### 예제 3

입력
```
1 1000000000
1000000000
```
출력
```
1000000000000000000
```
