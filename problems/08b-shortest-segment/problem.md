# 08b 가장 짧은 구간

단원: [08 투 포인터·슬라이딩 윈도우](../../units/08-two-pointers/README.md) · 난이도: 응용

## 문제

**양의 정수** N개로 이루어진 수열과 정수 S가 주어진다.
연속한 구간 중 원소의 합이 S **이상**인 것의 최소 길이를 구하라.
그런 구간이 없으면 0을 출력한다.

## 입력

- 첫째 줄: N S
- 둘째 줄: a_1 … a_N

## 출력

합이 S 이상인 연속 구간의 최소 길이(없으면 0)를 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- 1 ≤ a_i ≤ 10^9
- 1 ≤ S ≤ 10^15

## 예제

### 예제 1

입력
```
6 15
5 1 3 5 10 7
```
출력
```
2
```
[5, 10] 또는 [10, 7]. 원소 하나만으로는 15 이상이 되지 않는다.

### 예제 2

입력
```
3 100
1 2 3
```
출력
```
0
```
전체 합이 6이라 불가능하다.
