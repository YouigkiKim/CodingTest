# 모의 1-3 출입 기록

[모의시험 1](../../exams/exam1/README.md) · 3번

## 문제

어느 건물의 하루 출입 기록 N건이 시간 순서대로 주어진다. 각 기록은 `이름 in`(들어옴) 또는 `이름 out`(나감)이다.
하루가 시작될 때 건물은 비어 있다.

기록은 항상 유효하다. 즉 건물 안에 있는 사람이 다시 `in` 하거나, 건물 밖에 있는 사람이 `out` 하는 일은 없다.
같은 사람이 여러 번 드나들 수 있다.

모든 기록이 끝난 뒤 **건물 안에 남아 있는 사람**의 수와 이름을 구하라.

## 입력

- 첫째 줄: N
- 다음 N개 줄: 이름과 `in` 또는 `out`이 공백으로 구분되어 주어진다.

## 출력

- 첫째 줄: 남아 있는 사람 수 K
- 다음 K개 줄: 남아 있는 사람의 이름을 **사전순**으로 한 줄에 하나씩 (K = 0이면 첫째 줄만 출력)

## 제한

- 1 ≤ N ≤ 100,000
- 이름: 영어 소문자 1~10자

## 예제

### 예제 1

입력
```
5
kim in
lee in
kim out
park in
kim in
```
출력
```
3
kim
lee
park
```
kim은 나갔다가 다시 들어왔다.

### 예제 2

입력
```
2
a in
a out
```
출력
```
0
```
