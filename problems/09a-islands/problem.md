# 09a 섬의 개수

단원: [09 BFS·DFS](../../units/09-bfs-dfs/README.md) · 난이도: 기본

## 문제

세로 H칸, 가로 W칸인 지도가 주어진다. `#`은 땅, `.`은 바다다.
상하좌우로 이어진 땅 칸들의 덩어리를 섬 하나로 본다(대각선은 이어진 것이 아니다).
섬의 개수를 구하라.

## 입력

- 첫째 줄: H W
- 다음 H개 줄: 길이 W의 문자열 (`#` 또는 `.`)

## 출력

섬의 개수를 출력한다.

## 제한

- 1 ≤ H, W ≤ 500

## 예제

### 예제 1

입력
```
3 4
#..#
#..#
..##
```
출력
```
2
```
왼쪽 위의 세로 2칸이 섬 하나, 오른쪽의 4칸이 섬 하나.

### 예제 2

입력
```
3 3
#.#
.#.
#.#
```
출력
```
5
```
대각선으로만 닿아 있으므로 모두 다른 섬이다.
