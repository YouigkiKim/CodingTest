# 모의 2-4 번지는 불

[모의시험 2](../../exams/exam2/README.md) · 4번

## 문제

세로 H칸, 가로 W칸인 창고의 평면도가 주어진다.

- `F`: 처음부터 불이 붙어 있는 칸 (1개 이상)
- `.`: 빈 칸 (불이 옮겨붙을 수 있다)
- `#`: 방화벽 (불이 붙지 않는다)

1분이 지날 때마다, 불이 붙어 있는 모든 칸에서 상하좌우로 인접한 빈 칸으로 불이 동시에 옮겨붙는다.

모든 빈 칸에 불이 붙을 때까지 걸리는 시간(분)을 구하라.
끝까지 불이 붙지 않는 빈 칸이 있다면 -1을 출력한다. 빈 칸이 처음부터 하나도 없다면 0이다.

## 입력

- 첫째 줄: H W
- 다음 H개 줄: 길이 W의 문자열

## 출력

걸리는 시간(분) 또는 -1을 출력한다.

## 제한

- 1 ≤ H, W ≤ 500
- `F`는 1개 이상 존재한다.

## 예제

### 예제 1

입력
```
3 4
F...
.#..
...F
```
출력
```
2
```
1분 뒤 각 불씨의 이웃 칸들에, 2분 뒤 나머지 빈 칸 모두에 불이 붙는다.

### 예제 2

입력
```
1 3
F#.
```
출력
```
-1
```
방화벽 너머의 빈 칸에는 불이 닿지 않는다.

### 예제 3

입력
```
1 5
..F..
```
출력
```
2
```
