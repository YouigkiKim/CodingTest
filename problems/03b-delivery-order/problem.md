# 03b 배달 순서

단원: [03 완전탐색](../../units/03-brute-force/README.md) · 난이도: 응용

## 문제

배달 기사가 1번 장소(가게)에서 출발해 나머지 2번~N번 장소를 **모두 한 번씩** 방문해야 한다.
방문 순서는 자유롭게 정할 수 있고, 마지막 장소에서 가게로 돌아올 필요는 없다.

장소 i에서 장소 j로 바로 이동하는 거리 d(i, j)가 주어진다. d(i, j)와 d(j, i)는 다를 수 있다(일방통행 등).
이동은 항상 "현재 장소에서 다음 방문 장소로 바로" 가는 것으로 계산한다.

총 이동 거리의 최솟값을 구하라.

## 입력

- 첫째 줄: N
- 다음 N개 줄: 각 줄에 정수 N개. i번째 줄의 j번째 수가 d(i, j)이다. d(i, i) = 0.

## 출력

총 이동 거리의 최솟값을 출력한다.

## 제한

- 2 ≤ N ≤ 8
- 0 ≤ d(i, j) ≤ 1,000,000

## 예제

### 예제 1

입력
```
3
0 5 2
5 0 4
2 4 0
```
출력
```
6
```
1 → 2 → 3: 5 + 4 = 9. 1 → 3 → 2: 2 + 4 = 6. 최솟값은 6.

### 예제 2

입력
```
3
0 1 10
100 0 100
1 1 0
```
출력
```
11
```
1 → 2 → 3: 1 + 100 = 101. 1 → 3 → 2: 10 + 1 = 11.
처음에 가까운 2번으로 가는 것이 오히려 손해다.
