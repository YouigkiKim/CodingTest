# 05b 합이 K인 구간

단원: [05 누적합](../../units/05-prefix-sum/README.md) · 난이도: 응용

## 문제

정수 N개로 이루어진 수열 a_1, …, a_N과 정수 K가 주어진다.
연속한 구간(길이 1 이상) 중 원소의 합이 정확히 K인 구간의 개수를 구하라.
시작 위치나 끝 위치가 다르면 다른 구간이다. 원소는 **음수일 수 있다**.

## 입력

- 첫째 줄: N K
- 둘째 줄: a_1 … a_N

## 출력

합이 K인 구간의 개수를 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- -10^9 ≤ a_i ≤ 10^9
- -10^15 ≤ K ≤ 10^15

## 예제

### 예제 1

입력
```
5 3
1 2 1 2 1
```
출력
```
4
```
[1,2], [2,1], [1,2], [2,1] (위치 1~2, 2~3, 3~4, 4~5).

### 예제 2

입력
```
4 0
1 -1 1 -1
```
출력
```
4
```
위치 1~2, 2~3, 3~4, 1~4.
