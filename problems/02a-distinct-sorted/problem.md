# 02a 중복 없는 정렬

단원: [02 정렬](../../units/02-sorting/README.md) · 난이도: 기본

## 문제

정수 N개가 주어진다. 중복된 값을 하나만 남기고, 오름차순으로 정렬해 출력하라.

## 입력

- 첫째 줄: N
- 둘째 줄: 정수 N개

## 출력

- 첫째 줄: 서로 다른 값의 개수 K
- 둘째 줄: 서로 다른 값 K개를 오름차순으로, 공백으로 구분해 출력

## 제한

- 1 ≤ N ≤ 200,000
- -10^9 ≤ 각 정수 ≤ 10^9

## 예제

### 예제 1

입력
```
5
3 1 3 2 1
```
출력
```
3
1 2 3
```

### 예제 2

입력
```
4
7 7 7 7
```
출력
```
1
7
```
