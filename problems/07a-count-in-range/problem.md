# 07a 범위 안의 개수

단원: [07 이분탐색](../../units/07-binary-search/README.md) · 난이도: 기본

## 문제

정수 N개가 주어진다(정렬되어 있지 않다). Q개의 질문이 주어지며, 각 질문은
"값이 lo 이상 hi 이하인 정수는 몇 개인가?"이다. 모든 질문에 답하라.

## 입력

- 첫째 줄: N Q
- 둘째 줄: 정수 N개
- 다음 Q개 줄: lo hi

## 출력

각 질문의 답을 한 줄에 하나씩 출력한다.

## 제한

- 1 ≤ N, Q ≤ 100,000
- -10^9 ≤ 각 정수, lo, hi ≤ 10^9
- lo ≤ hi

## 예제

### 예제 1

입력
```
5 3
4 1 7 4 9
4 4
1 9
5 6
```
출력
```
2
5
0
```
4는 두 개, 1~9 범위에는 전부(5개), 5~6 범위에는 없다.

### 예제 2

입력
```
4 3
-3 -3 0 3
-3 -3
-1000000000 1000000000
-2 2
```
출력
```
2
4
1
```
