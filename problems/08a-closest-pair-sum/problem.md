# 08a 가장 가까운 합

단원: [08 투 포인터·슬라이딩 윈도우](../../units/08-two-pointers/README.md) · 난이도: 기본

## 문제

**오름차순으로 정렬된** 정수 N개와 목표값 T가 주어진다.
서로 다른 위치의 두 수를 골라 더했을 때, 그 합과 T의 차이(절댓값)의 최솟값을 구하라.

## 입력

- 첫째 줄: N T
- 둘째 줄: 정수 N개 (a_1 ≤ a_2 ≤ … ≤ a_N)

## 출력

`|a_i + a_j - T|` (i ≠ j)의 최솟값을 출력한다.

## 제한

- 2 ≤ N ≤ 200,000
- -10^9 ≤ a_i ≤ 10^9
- -2×10^9 ≤ T ≤ 2×10^9

## 예제

### 예제 1

입력
```
5 13
1 2 4 8 16
```
출력
```
1
```
4 + 8 = 12가 13에 가장 가깝다. 차이는 1.

### 예제 2

입력
```
4 100
1 2 3 4
```
출력
```
93
```
가장 큰 합은 3 + 4 = 7이다.
