# 05a 구간 합 질의

단원: [05 누적합](../../units/05-prefix-sum/README.md) · 난이도: 기본

## 문제

정수 N개로 이루어진 수열 a_1, …, a_N이 있다. Q개의 질문이 주어지며,
각 질문은 "l번째부터 r번째까지(양 끝 포함)의 합은 얼마인가?"이다. 모든 질문에 답하라.

## 입력

- 첫째 줄: N Q
- 둘째 줄: a_1 … a_N
- 다음 Q개 줄: l r

## 출력

각 질문의 답을 한 줄에 하나씩 출력한다.

## 제한

- 1 ≤ N, Q ≤ 200,000
- -10^9 ≤ a_i ≤ 10^9
- 1 ≤ l ≤ r ≤ N

## 예제

### 예제 1

입력
```
5 3
1 2 3 4 5
1 5
2 4
3 3
```
출력
```
15
9
3
```

### 예제 2

입력
```
3 2
1000000000 1000000000 1000000000
1 3
2 3
```
출력
```
3000000000
2000000000
```
답이 32비트 정수 범위를 넘을 수 있다.
