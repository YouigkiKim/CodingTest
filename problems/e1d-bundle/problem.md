# 모의 1-4 묶음 포장

[모의시험 1](../../exams/exam1/README.md) · 4번

## 문제

컨베이어 벨트 위에 상자 N개가 한 줄로 놓여 있고, i번째 상자에는 물건이 a_i개 들어 있다.
**연속한** 상자 몇 개(1개 이상)를 골라 그 안의 물건을 모두 꺼낸 뒤, M개씩 묶음으로 포장하려고 한다.
남는 물건 없이 포장하려면 꺼낸 물건의 총개수가 M의 배수여야 한다(0개도 M의 배수로 본다).

조건을 만족하도록 연속한 상자를 고르는 방법의 수를 구하라.
시작 상자나 끝 상자가 다르면 다른 방법이다.

## 입력

- 첫째 줄: N M
- 둘째 줄: a_1 … a_N

## 출력

방법의 수를 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- 1 ≤ M ≤ 10^9
- 0 ≤ a_i ≤ 10^9

## 예제

### 예제 1

입력
```
5 3
1 2 3 4 5
```
출력
```
7
```
[1,2], [3], [1,2,3], [2,3,4], [4,5], [3,4,5], [1,2,3,4,5]. 합은 차례로 3, 3, 6, 9, 9, 12, 15.

### 예제 2

입력
```
3 7
1 2 3
```
출력
```
0
```

### 예제 3

입력
```
4 2
0 0 0 0
```
출력
```
10
```
어떤 구간을 골라도 합이 0이다. 구간은 모두 10개.
