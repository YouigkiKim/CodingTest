# 06a 괄호 검사

단원: [06 스택·큐·힙](../../units/06-stack-queue-heap/README.md) · 난이도: 기본

## 문제

`(`, `)`, `[`, `]`, `{`, `}` 여섯 종류의 문자로만 이루어진 문자열이 T개 주어진다.
각 문자열이 **올바른 괄호 문자열**인지 판정하라.

올바른 괄호 문자열이란 모든 여는 괄호가 같은 종류의 닫는 괄호와 짝을 이루고,
짝들이 서로 엇갈리지 않는 문자열이다. 예를 들어 `([]{})`는 올바르지만 `([)]`, `((`, `)(`는 올바르지 않다.

## 입력

- 첫째 줄: T
- 다음 T개 줄: 괄호 문자열이 한 줄에 하나씩 (공백 없음, 길이 1 이상)

## 출력

각 문자열에 대해 올바르면 `YES`, 아니면 `NO`를 한 줄에 하나씩 출력한다.

## 제한

- 1 ≤ T ≤ 1,000
- 모든 문자열 길이의 합 ≤ 200,000

## 예제

### 예제 1

입력
```
6
()
([]{})
(]
((
)(
{[()]}[]
```
출력
```
YES
YES
NO
NO
NO
YES
```
`(]`는 종류가 다르고, `((`는 닫히지 않았고, `)(`는 여는 괄호 없이 닫는 괄호가 먼저 나온다.

### 예제 2

입력
```
2
([)]
(((())))
```
출력
```
NO
YES
```
`([)]`는 괄호의 개수는 맞지만 짝이 엇갈린다.
