# 10b 점검 지점

단원: [10 그리디 기초](../../units/10-greedy/README.md) · 난이도: 응용

## 문제

수직선 위에 순찰 구간 N개가 있다. i번째 구간은 좌표 l_i부터 r_i까지(양 끝 포함)다.
수직선의 정수 좌표에 점검 지점을 설치하려고 한다. **모든 구간이 점검 지점을 적어도 하나 포함**하도록 할 때,
필요한 점검 지점의 최소 개수를 구하라. 한 지점이 여러 구간에 동시에 포함될 수 있다.

## 입력

- 첫째 줄: N
- 다음 N개 줄: l_i r_i

## 출력

점검 지점의 최소 개수를 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- -10^9 ≤ l_i ≤ r_i ≤ 10^9

## 예제

### 예제 1

입력
```
3
1 4
2 6
5 8
```
출력
```
2
```
예를 들어 좌표 4와 8. 4는 [1,4]와 [2,6]에, 8은 [5,8]에 포함된다. 한 지점으로는 [1,4]와 [5,8]을 동시에 덮을 수 없다.

### 예제 2

입력
```
3
1 10
2 3
4 5
```
출력
```
2
```
좌표 3과 5. [1,10]은 둘 다 포함한다.
