# 01b 로봇 이동 - 힌트

[문제로 돌아가기](problem.md)

힌트는 한 단계씩만 펼쳐 보세요. 1단계를 보고 최소 10분은 다시 시도한 뒤 2단계를 보는 것을 권장합니다.

<details>
<summary>힌트 1단계</summary>

로봇의 상태는 (행, 열, 방향) 세 가지다. 방향을 문자 대신 **0~3의 숫자**로 표현해 보자.
시계 방향 순서(동 → 남 → 서 → 북)로 번호를 매기면 회전이 덧셈 한 번이 된다.

</details>

<details>
<summary>힌트 2단계</summary>

- 오른쪽 회전: `dir = (dir + 1) % 4`, 왼쪽 회전: `dir = (dir + 3) % 4` (`-1`을 쓰면 음수가 될 수 있다).
- 방향별 이동량을 배열로 둔다: `dr[4] = {0, 1, 0, -1}`, `dc[4] = {1, 0, -1, 0}`.
- `F`일 때 다음 칸 `(r + dr[dir], c + dc[dir])`을 **먼저 계산**하고, 1 ≤ 행 ≤ H, 1 ≤ 열 ≤ W일 때만 이동한다.

</details>
