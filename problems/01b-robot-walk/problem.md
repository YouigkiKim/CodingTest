# 01b 로봇 이동

단원: [01 배열·문자열·구현](../../units/01-array-string/README.md) · 난이도: 응용

## 문제

세로 H칸, 가로 W칸인 격자가 있다. 맨 위 행이 1행, 맨 왼쪽 열이 1열이다.
로봇은 (1행, 1열)에서 **동쪽**(열 번호가 커지는 방향)을 바라보고 출발한다.

로봇은 명령 문자열 S의 문자를 왼쪽부터 하나씩 수행한다.

- `L`: 제자리에서 왼쪽으로 90도 회전한다.
- `R`: 제자리에서 오른쪽으로 90도 회전한다.
- `F`: 바라보는 방향으로 한 칸 전진한다. 단, 전진하면 격자를 벗어나는 경우 그 명령은 **무시**한다(위치와 방향 모두 그대로).

참고: 동쪽을 보고 오른쪽으로 돌면 남쪽(행 번호가 커지는 방향)을, 왼쪽으로 돌면 북쪽을 보게 된다.

모든 명령을 수행한 뒤 로봇의 위치와, 무시된 `F` 명령의 수를 구하라.

## 입력

- 첫째 줄: H W
- 둘째 줄: 명령 문자열 S (`L`, `R`, `F`로만 이루어짐)

## 출력

최종 행 번호, 최종 열 번호, 무시된 명령 수를 공백으로 구분해 출력한다.

## 제한

- 1 ≤ H, W ≤ 1,000
- 1 ≤ |S| ≤ 200,000

## 예제

### 예제 1

입력
```
3 4
FFRFLF
```
출력
```
2 4 0
```
(1,1)동 → F (1,2) → F (1,3) → R 남쪽을 봄 → F (2,3) → L 동쪽을 봄 → F (2,4).

### 예제 2

입력
```
3 3
RFFFRF
```
출력
```
3 1 2
```
R로 남쪽을 본다. F (2,1) → F (3,1) → F는 격자를 벗어나므로 무시(1회) → R로 서쪽을 봄 → F는 무시(2회).
