# 모의 2-2 징검다리

[모의시험 2](../../exams/exam2/README.md) · 2번

## 문제

강에 돌 N개가 일렬로 놓여 있다. 강가에서 가까운 순서대로 1번, 2번, …, N번 돌이며 N번 돌이 건너편에 닿아 있다.
각 돌에는 점수 s_i가 적혀 있다(음수일 수 있다). 돌을 밟으면 그 돌의 점수를 얻는다.

강가에서 출발해 한 번 뛸 때마다 **바로 다음 돌** 또는 **한 칸 건너뛴 돌**로 이동할 수 있다.
즉 강가에서는 1번 또는 2번 돌로, i번 돌에서는 i+1번 또는 i+2번 돌로 갈 수 있다.
반드시 **N번 돌을 밟고** 끝나야 한다.

얻을 수 있는 점수 합의 최댓값을 구하라.

## 입력

- 첫째 줄: N
- 둘째 줄: s_1 … s_N

## 출력

점수 합의 최댓값을 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- -10^9 ≤ s_i ≤ 10^9

## 예제

### 예제 1

입력
```
5
3 -5 2 -1 4
```
출력
```
9
```
1번, 3번, 5번 돌을 밟는다: 3 + 2 + 4 = 9.

### 예제 2

입력
```
3
-1 -2 -3
```
출력
```
-4
```
1번 → 3번: -1 + -3 = -4. (2번 → 3번은 -5, 모두 밟으면 -6)

### 예제 3

입력
```
2
-3 5
```
출력
```
5
```
강가에서 바로 2번 돌로 뛴다.
