# 모의 2-2 징검다리 - 힌트

[문제로 돌아가기](problem.md)

모의시험 시간이 끝난 뒤, 풀지 못한 문제를 다시 시도할 때 한 단계씩 펼쳐 보세요.

<details>
<summary>힌트 1단계</summary>

i번 돌을 밟기 바로 직전에 있던 곳은 i-1번 돌 또는 i-2번 돌(혹은 강가)이다.
"i번 돌을 밟았을 때까지의 최대 점수"를 앞의 두 값으로 표현해 보자.

</details>

<details>
<summary>힌트 2단계</summary>

강가를 점수 0인 "0번 돌"로 생각한다.

- `best[0] = 0`, `best[1] = s[1]`
- `best[i] = max(best[i-1], best[i-2]) + s[i]` (i ≥ 2)
- 답: `best[N]`

점수가 모두 음수일 수 있으므로 "0과 비교해 큰 값"을 취하는 식의 처리를 넣으면 안 된다. `long long` 사용.

</details>
