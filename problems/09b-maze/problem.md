# 09b 미로 탈출

단원: [09 BFS·DFS](../../units/09-bfs-dfs/README.md) · 난이도: 응용

## 문제

세로 H칸, 가로 W칸인 미로가 주어진다.

- `S`: 출발 칸 (정확히 1개)
- `E`: 도착 칸 (정확히 1개)
- `.`: 빈 칸
- `#`: 벽

한 번에 상하좌우로 인접한 칸으로 한 칸 이동할 수 있고, 벽과 미로 밖으로는 갈 수 없다.
출발 칸에서 도착 칸까지 가는 **최소 이동 횟수**를 구하라. 갈 수 없다면 -1을 출력한다.

## 입력

- 첫째 줄: H W
- 다음 H개 줄: 길이 W의 문자열

## 출력

최소 이동 횟수 또는 -1을 출력한다.

## 제한

- 1 ≤ H, W ≤ 500
- H × W ≥ 2

## 예제

### 예제 1

입력
```
3 4
S..#
.#..
...E
```
출력
```
5
```
예: 아래, 아래, 오른쪽, 오른쪽, 오른쪽.

### 예제 2

입력
```
1 3
S#E
```
출력
```
-1
```
