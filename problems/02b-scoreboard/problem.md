# 02b 대회 순위표

단원: [02 정렬](../../units/02-sorting/README.md) · 난이도: 응용

## 문제

프로그래밍 대회에 N개 팀이 참가했다. 각 팀의 이름, 푼 문제 수, 벌점이 주어진다.
다음 규칙으로 순위를 매겨 1등부터 차례로 팀 이름을 출력하라.

1. 푼 문제 수가 **많은** 팀이 앞선다.
2. 푼 문제 수가 같으면 벌점이 **적은** 팀이 앞선다.
3. 벌점도 같으면 이름이 **사전순으로 앞서는** 팀이 앞선다.

## 입력

- 첫째 줄: N
- 다음 N개 줄: 팀 이름, 푼 문제 수, 벌점이 공백으로 구분되어 주어진다.

## 출력

순위가 높은 팀부터 이름을 한 줄에 하나씩 출력한다.

## 제한

- 1 ≤ N ≤ 100,000
- 팀 이름: 영어 소문자 1~10자, 모든 팀의 이름은 서로 다르다.
- 0 ≤ 푼 문제 수 ≤ 20
- 0 ≤ 벌점 ≤ 10^9

## 예제

### 예제 1

입력
```
4
kim 3 120
lee 5 300
park 3 100
choi 5 300
```
출력
```
choi
lee
park
kim
```
5문제를 푼 choi와 lee가 앞선다. 둘은 벌점도 300으로 같으므로 사전순으로 choi가 먼저다.
3문제를 푼 팀 중에서는 벌점이 적은 park이 kim보다 앞선다.

### 예제 2

입력
```
3
x 2 50
y 3 999
z 2 49
```
출력
```
y
z
x
```
