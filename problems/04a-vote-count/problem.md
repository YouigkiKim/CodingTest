# 04a 투표 집계

단원: [04 해시·집합](../../units/04-hash-set/README.md) · 난이도: 기본

## 문제

N장의 투표 용지에 후보의 이름이 하나씩 적혀 있다. 가장 많은 표를 받은 후보의 이름과 득표수를 구하라.
최다 득표자가 여러 명이면 이름이 **사전순으로 가장 앞서는** 후보를 답한다.

## 입력

- 첫째 줄: N
- 다음 N개 줄: 후보 이름이 한 줄에 하나씩

## 출력

당선자의 이름과 득표수를 공백으로 구분해 출력한다.

## 제한

- 1 ≤ N ≤ 200,000
- 이름: 영어 소문자 1~10자

## 예제

### 예제 1

입력
```
5
kim
lee
kim
park
lee
```
출력
```
kim 2
```
kim과 lee가 2표로 같다. 사전순으로 앞서는 kim을 답한다.

### 예제 2

입력
```
6
ab
a
ab
abc
ab
a
```
출력
```
ab 3
```
