# 11a 계단 오르기

단원: [11 DP 기초](../../units/11-dp/README.md) · 난이도: 기본

## 문제

바닥(0번 칸)에서 출발해 N번 칸까지 계단을 오른다. 한 번에 1칸, 2칸, 또는 3칸을 오를 수 있다.
계단 중 M개의 칸은 부서져 있어 **밟을 수 없다**(건너뛰는 것은 가능). N번 칸은 부서져 있지 않다.

N번 칸에 정확히 도착하는 방법의 수를 1,000,000,007로 나눈 나머지를 구하라.
밟는 칸의 순서가 하나라도 다르면 다른 방법이다.

## 입력

- 첫째 줄: N M
- 둘째 줄: 부서진 칸의 번호 M개 (M = 0이면 이 줄은 없다)

## 출력

방법의 수를 1,000,000,007로 나눈 나머지를 출력한다.

## 제한

- 1 ≤ N ≤ 1,000,000
- 0 ≤ M ≤ N - 1
- 부서진 칸 번호는 1 이상 N - 1 이하이며 서로 다르다.

## 예제

### 예제 1

입력
```
4 0
```
출력
```
7
```
1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2, 1+3, 3+1.

### 예제 2

입력
```
4 1
2
```
출력
```
3
```
2번 칸을 밟지 않는 방법: 0→1→3→4, 0→1→4, 0→3→4.

### 예제 3

입력
```
5 3
2 3 4
```
출력
```
0
```
1번 칸에서 5번 칸까지는 4칸 차이라 한 번에 갈 수 없다.
